# KNU 수강신청 연습 페이지

정적 파일만으로 동작하는 수강신청 연습용 페이지입니다.

- `index.html`을 브라우저에서 열면 바로 실행됩니다.
- 과목 데이터는 `data/courses.csv`에서 읽고, 파일 직접 열기 환경을 위해 `data/courses-data.js` fallback도 함께 사용합니다.
- 과목 목록은 2026-08-03 기준 경북대학교 수업시간표 및 강의계획서 조회의 `2026학년도 / 2학기 / 전문대학원 / 법학전문대학원 / 법학과` 조회 결과 68건입니다.
- 입력용 `courseCode`는 분반을 포함하고 하이픈을 제거한 값입니다. 예: `LAWS0703-001` → `LAWS0703001`.
- 조회 당시의 원본 행은 `data/courses-source.json`에 함께 보관합니다.
