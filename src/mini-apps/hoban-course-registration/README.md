# 호반대학교 수강신청 연습

`/Users/haryun/Desktop/Development/sugang-master`의 정적 수강신청 페이지를 기반으로 Law Solver 미니 앱에서 일반 연습과 10초 챌린지 모드를 제공합니다.

## 구현 원칙

- 원본 문서의 `body` 스타일과 해시 라우팅을 다른 Law Solver 화면과 충돌 없이 유지하기 위해 `HobanCourseRegistrationPage.tsx`는 정적 앱을 전체 화면 iframe으로 실행합니다.
- 원본 이미지와 강좌 데이터는 유지하고, 챌린지 GNB·가상 시계·결과 모달은 `public/mini-apps/hoban-course-registration/`의 HTML, CSS, JavaScript에서 관리합니다.
- 챌린지 기록은 서버나 localStorage에 저장하지 않고 현재 페이지 메모리에만 유지합니다.

## 챌린지 모드

- 시작하면 로그인 화면으로 돌아가 신청 목록을 초기화하고 `16:59:50`부터 10초를 카운트다운합니다.
- `17:00:00` 전에도 로그인 버튼은 그대로 동작하지만 누르면 `수강신청 기간이 아닙니다` 경고를 표시하고, 정각부터 로그인과 수강신청을 진행할 수 있습니다.
- 과목별 시간은 `17:00:00.000`부터 신청 성공 시점까지의 누적 경과 시간이며 밀리초 단위로 표시합니다. 결과에는 사용자가 입력한 분반 포함 전체 과목코드, 담당교수와 마지막 과목 완료 시각을 기준으로 한 올클리어 시간을 함께 표시합니다.
- 결과에서 다시 시작하거나 챌린지만 종료하거나 Law Solver 미니 앱 목록으로 돌아갈 수 있습니다.

## 접근 제어

- `/apps` 목록에서는 공통 `PremiumBadge`로 Premium 전용 앱임을 표시합니다.
- React 라우트에서 `useAccountStore`의 초기화·로그인·활성 Premium 상태를 확인하고, 조건을 충족할 때만 정적 iframe을 렌더링합니다.
- 비로그인 사용자는 계정 로그인으로, 로그인했지만 활성 Premium 회원권이 없는 사용자는 Premium 탭으로 안내합니다.
- 이 제어는 편의상 프론트에서 직접 접근을 막는 수준이며 서버 권한 검증으로 사용하지 않습니다.
