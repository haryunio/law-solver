# 제17회 법조윤리시험 가답안

제17회 법조윤리시험의 1차 가답안과 문항별 핵심 해설을 확인하고 답안 40개를 자동채점하는 단일 페이지 미니 앱입니다.

## 목표와 MVP

- 1~40번 가답안을 10문항 단위 표로 표시합니다.
- 각 답을 누르면 같은 페이지의 해당 문항 해설로 이동합니다.
- 40개 문항의 핵심 쟁점과 가답안 근거를 모두 표시합니다.
- 1~4 숫자를 붙여 쓰거나 공백·쉼표로 구분해 입력하면 40개가 채워지는 즉시 점수와 오답을 계산합니다.
- 모바일, 다크 모드, 키보드 포커스와 Law Solver 공통 디자인을 지원합니다.

## 데이터

`data.ts`가 문항 번호, 가답안, 쟁점명, 핵심 해설의 단일 원본입니다. 최초 데이터는 사용자가 제공한 `제17회_법조윤리시험_사진추출_가답안_해설.md`를 기준으로 작성했습니다. 이 자료는 시험지 사진을 판독한 1차 가답안이며 공식 정답이 아닙니다.

공식 정답 확인 뒤 내용을 수정할 때에는 `data.ts`와 `data.test.ts`의 정답 배열을 함께 갱신합니다.

## 제외 범위

- 사용자별 기록 및 localStorage 저장
- 서버 API와 Premium 데이터 연동
- 시험지 원문 전체 제공
